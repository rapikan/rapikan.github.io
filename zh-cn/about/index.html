零配置超级格式化工具背后的故事。

Rapikan 是如何开始的

这一切都始于我在 VS Code 中找不到开箱即用的 Java 和 Kotlin 格式化工具。大多数都需要繁琐的手动系统安装——比如为 Java 配置 google-java-format，为 Kotlin 配置 ktlint。于是我决定自己动手去构建一个自动处理这些二进制文件的包装器。

接着我想加入对 JS 和 TSX 的支持。起初，我尝试从零开始硬编码格式化逻辑！但这太耗时了。经过一番研究，我发现大家都觉得 Prettier 对开发者更友好。所以我重构了代码，在底层接入了 Prettier，并处理了所有的内部逻辑，让它无缝运行。

在成功集成 Prettier 之后，我一发不可收拾。每当我在 VS Code 中打开一种新类型的文件发现它没有被格式化时，我就会自发地添加对该语言的支持。从 Android Gradle 脚本到各种配置文件，再到其他后端语言。不知不觉中，我已经提交了数百次代码，这个扩展现在已经在一个本地系统中编排了数十个不同的格式化程序。为了让这个工具在全球范围更易用，我还为其用户界面添加了多语言支持。

为什么会有付费版本？

老实说，从初中起我就一直靠各种免费工具生存，我个人也不喜欢订阅制。我想得太多了：'真的会有人买一个 .vsix 扩展吗？不过，如果有 100 万家公司买了许可证，我下半辈子就可以安心退休了，哈哈哈。'

定价理念

所以我找到了一个折中方案：对于个人、学生和开源项目，Rapikan 是 100% 免费的，没有任何限制。

但是，对于公司和团队，我们提供每年 49 美元的 Pro 许可证。技术生态在不断变化，这笔年度费用能让我长期维护这 50 多种语言。您的团队不仅能节省大量的配置时间，还能直接支持一个独立开发者的工作。

— Nabil Aba
